# Satellite orbiting Earth
This assignment can be completed outside of the ROS2 container of this course. 
See [below](#optional-environment-setup) for a recommended way to work inside the container.

## Completing the Assignment
Finish the implementation of `satellite.py` by completing the sections marked as `# STUDENT CODE START` and `# STUDENT CODE END`. 
Do not make modifications anywhere else.

## **Optional** environment setup
Follow these steps to run code in the same container as the one used in questions involving ROS2.

1. Build your ROS2 workspace according to instructions in assignment 0
2. Unzip package into the `py/` folder
3. Run the starter script as follows. Running the script will also generate the plots required for the question.
```bash
python3 /workspaces/ros2_ws/py/satellite/satellite.py
```
